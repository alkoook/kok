# KOK

تطبيق عربي Mobile First لتسجيل وحساب نتائج تركس البطيئة والسريعة، طرنيب 61، وطرنيب 41. يعمل محلياً دون خادم، ويحفظ المباريات في IndexedDB، ويمكن تثبيته كتطبيق PWA.

## التشغيل والتدقيق

```bash
npm install
npm run dev
npm test
npm run lint
npm run build
npm run preview
```

ينتج البناء مجلد `dist/` ثابتاً يمكن نشره على استضافة HTTPS. لا تفتح `index.html` عبر `file://` لأن Service Worker يحتاج `localhost` أو HTTPS.

## قواعد الإصدار الثاني

- تركس: لعب فردي أو شراكة، تدبيل شيخ الكبة وكل بنت على حدة، وتحقق أن مجموع كل مملكة مكتملة يساوي صفراً.
- طرنيب 61: محرك V2 ثابت للضمانات من 7 إلى 13 والكبوت.
- طرنيب 41: نقاط وضمانات فردية ومراحل Normal و30 وBlocked 41. يتحقق المحرك مستقلاً من أن مجموع ضمانات اللاعبين الأربعة لا يقل عن 11.
- كل مباراة تحفظ `rulesSnapshot` و`rulesVersion` حتى لا تتغير نتائج المباريات القديمة عند تحديث القواعد.

## التخزين والنسخ الاحتياطي

المباريات والجولات والأسماء والإعدادات محفوظة محلياً عبر Dexie. يدعم الاستيراد ملفات النسخ الاحتياطي القديمة والجديدة، بينما تصدّر النسخة الحالية مخطط KOK V2. لا توجد Analytics أو API مطلوبة وقت التشغيل.

## مواضع المحركات

- قواعد وحساب تركس: `src/games/trix/`.
- قواعد وحساب طرنيب 61 و41: `src/games/tarneeb/`.
